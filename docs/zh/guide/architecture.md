# 系统架构

SoloMind 采用微服务架构设计，为超级个体提供灵活、可扩展的私域能力管理平台。

## 设计原则

1. **私域优先** - 所有数据本地存储，完全自主可控
2. **模块化** - 功能模块可独立部署和扩展
3. **AI 原生** - 深度集成 AI 能力，智能化处理
4. **简洁高效** - 面向个人用户，追求极致简洁

                  │

┌─────────────────▼───────────────────────────┐

│  ┌─────────┐ ┌─────────┐ ┌─────────┐       │

                  │

## 组件说明

| 组件 | 说明 |
|------|------|
| **Client Apps** | 多端客户端应用 |
| **API Gateway** | 统一的 API 入口和路由 |
| **Agent** | AI 意图识别和参数提取 |
| **Workflow** | 工作流编排和执行 |
| **User** | 用户管理服务 |
| **Redis** | 高性能数据存储层 |
