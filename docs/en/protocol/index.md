# Protocol Specifications

This section contains the core protocol specification documents for the SoloMind system.

## Protocol List

| Protocol | Description |
|----------|-------------|
| [Workflow Protocol](./workflow) | AI-driven workflow definition, parameter collection and execution |
| [Security Protocol](./security) | Zero-knowledge authentication and fine-grained access control |
| [Memory Protocol](./memory) | Client-side context memory management |
| [Approval Protocol](./approval) | Approval workflow data structures and processing |
| [Category Protocol](./category) | Microservice category registration and global discovery |
| [AI Test Protocol](./ai-test) | Workflow accuracy evaluation and automated testing |
| [Report Protocol](./report) | Generic report DSL definition |
