# SoloMind Mobile Client

SoloMind 移动端是一个基于 **React + TypeScript + Vite** 构建的轻量级、智能化的私有 AI 助手界面。它专为移动端单手操作优化，深度集成了 **Focus（意图聚焦）** 协议与 **STM（短期记忆）** 系统。

## 🌟 核心功能

### 1. 智能化意图聚焦 (Focus Mode)
- **动态参数提取**: 自动分析用户自然语言，实时填充业务场景所需的参数（如资产、价格、数量等）。
- **交互式确认卡片**: 通过 `SummaryCard` 直观展示当前任务状态，支持点击特定字段进行手动修正。
- **快捷指令支持**: 支持通过特定前缀（如 `:p`）或快捷键启动特定业务流程。

### 2. 多模态 AI 交互
- **文字对话**: 毫秒级意图匹配与对话响应。
- **视觉识别**: 集成 Qwen-VL 等视觉大模型能力，支持上传图片并根据图片内容自动匹配后续业务流程（如扫描报销单据）。
- **状态感知**: 系统能感知当前是否处于“任务处理中”或“普通聊天”模式。

### 3. 深层短期记忆系统 (STM)
- **业务上下文 (Operational)**: 自动记录最近搜索或创建的实体（仓库、单位、物品等），在后续对话中实现无感引用。
- **对话历史 (Conversation)**: 支持 5-10 轮交互上下文，确保 AI 理解复杂的长对话逻辑。
- **错误修正 (Correction)**: 记录执行失败的尝试，引导用户补充缺失信息而非简单报错。

### 4. 私有化安全保障
- **多账号管理**: 支持快速切换不同的用户身份。
- **本地 PIN 码保护**: 在保持登录状态的同时，提供类似银行 App 的本地 PIN 码二次校验，确保设备物理丢失时的隐私安全。
- **权限感知**: 根据后端下发的能力定义自动调整 UI 功能入口。

### 5. 极致视觉体验
- **多主题支持**: 预设浅色 (Light)、深色 (Dark)、海洋 (Ocean)、森林 (Forest) 等多种配色方案。
- **微交互**: 针对移动端触摸优化的手势、弹窗及反馈动画。
- **端侧校验**: 完善的全局错误监听与友好 Toast 提醒。

## 🛠 技术栈
- **框架**: React 18
- **语言**: TypeScript
- **构建工具**: Vite
- **样式**: Tailwind CSS
- **接口协议**: JSON-RPC 2.0
- **数据流**: 特制 Hooks 驱动的状态管理 (useFocus, useMemory, useChatLogic)

## 🚀 快速开始

1. **安装依赖** (在 `api/` 根目录下执行):
   ```bash
   npm install
   ```

2. **本地开发**:
   ```bash
   npm run dev
   ```

3. **构建发布**:
   ```bash
   npm run build
   ```
