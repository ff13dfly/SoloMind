# Client Applications

该文件夹 (`client/`) 包含了 SoloMind 的前端客户端应用和相关输出。

## 1. Mobile Client (`client/mobile`)

**角色**：Web 端手机风格入口。

这是一个基于 **React + TypeScript + Vite + Tailwind CSS** 构建的轻量级、智能化 Web 应用 (SPA)。它专为移动端单手操作优化，是 SoloMind 最核心的交互界面。

### 核心特性 (Key Features)

*   **智能化意图聚焦 (Focus Mode)**
    *   **动态参数提取**: 自动分析用户自然语言，实时填充业务场景所需的参数。
    *   **交互式确认卡片**: 直观展示当前任务状态，支持点击特定字段进行手动修正。
*   **多模态 AI 交互**
    *   **视觉识别**: 集成 Vision 模型能力，支持图片内容理解与业务流程匹配（如扫描单据）。
    *   **状态感知**: 自动区分“任务处理”与“闲聊”模式。
*   **深层短期记忆 (STM)**
    *   **业务上下文**: 自动记录最近操作的实体（仓库、单位等），实现对话中的无感引用。
    *   **错误修正**: 记录执行失败的尝试，引导用户补充缺失信息。
*   **私有化体验**
    *   **本地 PIN 码**: 提供端侧的安全校验。
    *   **多主题支持**: 内置浅色、深色、海洋、森林等多种配色。

## 2. iOS App (`client/ios`)

**角色**：Apple iOS 原生应用代码。

此处存放 SoloMind 的 iOS 客户端源代码（Swift/SwiftUI）。该客户端通常作为一个简单的“壳” (Wrapper) 或深度集成系统功能（如快捷指令、Siri、本地通知）的原生层，核心业务逻辑依然可能通过 Webview 复用 `client/mobile` 或直接通过 API 与后端通信。

---

## 3. Export Data (`client/export`)

**角色**：系统内容输出目录。

此目录用于存放 SoloMind 系统生成的、面向外部使用的静态内容或数据文件。例如：

*   **部署到网络的页面**: 生成的静态博客、报告页等。
*   **数据导出文件**: CSV, JSON 格式的业务数据备份或迁移文件。
*   **其他生成的资源**: 图片、PDF 报表等。

> 注意：此目录通常是 `.gitignore` 的一部分（除了示例文件），用于存放运行时的产物。
